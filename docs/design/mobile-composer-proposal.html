모바일 컴포저 축소안

화면 폭 860px 이하 기준. 모바일에서 사이드바(.chat-rail)는 이미 숨겨져 있으므로, 하단을 차지하는 것은 컴포저 영역(빠른명령 칩 + 입력창 + 안내문구) 하나뿐입니다.

지금 문제 — 컴포저가 약 138px을 항상 차지합니다. 375×667 화면에서 상단바까지 더하면 대화가 보이는 영역은 절반 남짓이고, 키보드가 올라오면 메시지 한두 개밖에 안 보입니다.
특히 "Enter로 보내기"는 모바일에서 의미가 없습니다 — 모바일 키보드에는 해당하는 동작이 없고 사용자는 전송 버튼을 누릅니다.

현재 138px

칩 44px + 입력 46px + 안내문구 20px + 상하 패딩 28px.
